# 暮崖跃台

一款横版 2D 平台跳跃游戏。信使沿着暮色崖壁奔跑，收集金币，躲开尖刺，踩上移动石台，在检查点点亮灯笼，最后把信送到终点旗帜。

## 怎么玩

- 方向键或 `WASD`：左右奔跑
- `W` / `↑` / 空格：跳跃，空中再按一次可以二段跳
- `S` / `↓`：从单向平台落下
- `P` 或 `Esc`：暂停
- 触碰尖刺或掉下悬崖会回到最近的检查点；金币计数保留已收集的部分
- 抵达旗帜即通关

开局可以选择轻松、普通、险峻三种难度。死亡或通关后可以重新开始。本机最佳用时和金币会记在浏览器里。

手机上可以用屏幕上的左右和跳跃按钮。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认在 `http://127.0.0.1:8080`。
